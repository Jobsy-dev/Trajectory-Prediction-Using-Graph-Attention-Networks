## 📖 Overview

This project investigates trajectory prediction using graph-based deep learning techniques. It focuses on preprocessing graph-structured trajectory data, preparing graph representations, and building a deep learning workflow for predicting future trajectories.

The implementation is organized into three notebooks that demonstrate the complete pipeline from data preparation to model development.

---

## 🎯 Objectives

- Load and preprocess trajectory datasets.
- Prepare graph-structured data.
- Normalize and transform node features.
- Build a deep learning pipeline using TensorFlow/Keras.
- Train and evaluate trajectory prediction models.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Jobsy-dev/Trajectory-Prediction-Using-Graph-Attention-Networks.git
```

Move into the project

```bash
cd Trajectory-Prediction-Using-Graph-Attention-Networks
```

Install dependencies

```bash
pip install tensorflow numpy pandas matplotlib scikit-learn jupyter
```

Launch Jupyter Notebook

```bash
jupyter notebook
```

Run the notebooks sequentially:

1. Task1.ipynb
2. Task2.ipynb
3. Task3.ipynb
